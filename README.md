# Calcio Notturno

Gioco di calcio 4 contro 4 nel browser. Apri `index.html` e gioca.

- **WASD / Frecce**: muovi il giocatore
- **Spazio**: tieni premuto e rilascia per tirare (senza palla: scatto)
- **X / K**: passaggio (senza palla: cambia giocatore)
- **P / Esc**: pausa

Su telefono compaiono joystick e pulsanti touch.
